> **日期**: 2026-04-23

## 一、项目概述

我们的报告系统已产出完整 JSON 数据 (321 字段)。您的工作是:
1. **精修现有 13 个页面的 CSS 排版** — 解决跨页断裂、表格对齐、字间距等问题
2. **新增 2 个页面模板** — M10 作文精讲 + M11 阅读精讲
3. **新增阅读进度边栏** — PDF 每页侧边显示当前模块位置
4. **页码、目录优化**

**注意**: 数学和英语共用同一套模板。模板通过 JSON 中的 `subject_name` 和 `page_visibility` 字段自动适配, 不需要做两套模板。

## 二、技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Python | 3.11+ | 渲染脚本 |
| Jinja2 | 3.1+ | 模板引擎 |
| Playwright | latest | HTML → PDF (Chromium) |
| CSS | 纯 CSS, 不用框架 | PDF 渲染, 不需兼容浏览器 |

### 环境搭建

```bash
pip install jinja2 playwright
playwright install chromium
```

### 渲染命令

```bash
# 生成 HTML
python scripts/render_standalone.py samples/json/sample_01_math.json -o output.html

# 生成 HTML + PDF
python scripts/render_standalone.py samples/json/sample_01_math.json -o output.html --pdf
```

## 三、数学 vs 英语: 同一套模板, 数据驱动

| 维度 | 数学 | 英语 | 模板处理方式 |
|------|------|------|-----------|
| 标题 | "数学" | "英语" | `{{ subject_name }}` |
| 领域数 | 6 (方程/函数/几何...) | 4 (词汇/语法/阅读/语言运用) | `{% for domain in domains.domain_items %}` 循环 |
| 知识点层级 | L1→L2→L3→L4 (4 级) | L1→L2→L3 (3 级) | `{% if kp_drill.tables.l4 %}` 条件渲染 |
| M5 城市考情 | 有 | 暂关 | `{% if page_visibility.m5_city_compare %}` |
| M10 作文精讲 | 无 | 有 (二期) | `{% if page_visibility.m10_composition %}` |
| M11 阅读精讲 | 无 | 有 (二期) | `{% if page_visibility.m11_reading_deep %}` |
| 写作提示卡 | 无 | M4 底部 | `{% if dp._composition_notice %}` |
| 目标分数 | 120/150 | 140/150 | `{{ summary.target_score_text }}` |

**排版要求**: 同一份模板在数学 6 领域和英语 4 领域时都正确排版, 表格列数自适应。

## 五、新增页面

### M10 作文精讲 (英语专属)

**条件**: `page_visibility.m10_composition == true`

**数据位置**: `composition_deep` (JSON 中)

**布局** (11 模块):

```
1. 题目原文
2. 学生原文
3. 成绩概览: 总分 X/20, 内容 X/8 + 语言 X/8 + 组织 X/4
4. 本次最该先改的两点
5. 题目分析
6. 内容分析 (X/8)
7. 语言问题分析 (X/8)
8. 结构与行文分析 (X/4)
9. 本周提升建议
10. 范文参考: 改写示范 + 高分范文
11. 问题与亮点一览
```

**排版要求**:
- 成绩概览用分数条/进度条可视化
- 范文用引用样式 (灰色背景 + 左边框)
- 学生原文与范文并排或上下对比

### M11 阅读精讲 (英语专属)

**条件**: `page_visibility.m11_reading_deep == true`

**数据位置**: `reading_deep` (JSON 中)

**布局** (7 区块):

```
1. 本篇阅读概览: 文章类型 + 题数 + 正确数
2. 为什么选这篇: 选文理由
3. 整体问题诊断: 阅读薄弱类型
4. 逐题讲解: 对题简析 + 错题详析 (引用原文)
5. 阅读方法: 可迁移的解题策略
6. 3天练习建议
7. 鼓励语
```

**排版要求**:
- 逐题讲解中错题用红色边框标注
- 原文引用用灰色背景 + 斜体
- 对题用绿色标记, 错题用红色标记

## 六、阅读进度边栏

**效果**: PDF 每页右侧 (或左侧) 有一个固定位置的模块导航条:

```
┌─────────────────────────┬──────┐
│                         │ ■ 摘要│
│     报告内容              │ □ 领域│
│                         │ □ 短板│
│                         │ ■ 钻取│  ← 当前模块高亮
│                         │ □ 考情│
│                         │ □ 建议│
│                         │ □ 逐题│
└─────────────────────────┴──────┘
```

- 当前模块: 深色/高亮
- 其他模块: 浅灰色
- 每个模块名称简写 (2-3 字)
- 位置固定, 不随内容滚动
- 数学和英语模块数不同 (6+共用 vs 5+作文+阅读), 边栏自适应

**实现建议**: 每个页面模板的容器加 CSS class 标记模块, 用 `@page` 或绝对定位实现。
