# 漫画图片功能使用说明

## 功能概述

为PDF报告增加了两个Q版漫画页面：
- **第3页（场景1）**：学习困境→寻求帮助
- **第4页（场景2）**：学习成长→成绩突破

## 学生等级分类

系统根据学生的当前准确率自动分类：
- **差生**（need_major）：准确率 < 60%
- **中等生**（room_grow）：60% ≤ 准确率 < 85%
- **优等生**（excellent）：准确率 ≥ 85%

## 图片文件放置位置

### 场景1（第3页）

**目录**：`static/comic/scene1/`

**文件命名**：
- `差生-中文.png` - 差生版本的漫画图片
- `中等生-中文.png` - 中等生版本的漫画图片
- `优等生-中文.png` - 优等生版本的漫画图片

**图片格式**：
- 统一使用 `.png` 格式
- 建议分辨率：长边 1500px 以上，保持清晰度

### 场景2（第4页）

**目录**：`static/comic/scene2/`

**文件命名**：
- `差生-中文.png` - 差生版本的漫画图片
- `中等生-中文.png` - 中等生版本的漫画图片
- `优等生-中文.png` - 优等生版本的漫画图片

**图片格式**：
- 统一使用 `.png` 格式
- 建议分辨率：长边 1500px 以上，保持清晰度

## 视觉风格

漫画页面严格遵循 `samples/html/preview.html` 的 Cyan/Purple/Orange 主题：

## 图片内文案策略

当前提示词不再要求图片保留空白区域，也不依赖系统二次填充文字。生成图片时直接在画面内生成合适的示例内容：

### 场景1画面文案
- 试卷直接生成示例诊断分数和学习状态。
- 宣传海报直接生成机构服务卖点。
- 机构门头和立牌直接生成机构名称与欢迎语。

### 场景2画面文案
- 到店标签直接生成课程阶段或到达信息。
- 学习材料直接生成训练主题。
- 成绩单直接生成示例提升结果。
- 庆祝横幅和奖状直接生成庆祝语。

### 机构名称
- 当前提示词使用机构占位名：`星航优学中心`
- 正式机构名称确定后，全文替换该名称。
- 为保留历史记录，替换后应新建提示词版本，不覆盖旧版本。

## 使用流程

### 1. 生成漫画图片
使用AI绘图工具（Midjourney / DALL-E 3 / 通义万相等）和提示词生成漫画图片：

**当前提示词版本**：`prompts/comic/versions/v2026-04-29-filled-content/`

**场景1提示词目录**：`prompts/comic/versions/v2026-04-29-filled-content/prompts/scene1/`
- `差生-中文.md`
- `中等生-中文.md`
- `优等生-中文.md`

**场景2提示词目录**：`prompts/comic/versions/v2026-04-29-filled-content/prompts/scene2/`
- `差生-中文.md`
- `中等生-中文.md`
- `优等生-中文.md`

生成图片保存到同版本提示词目录，和对应 `.md` 提示词放在一起：

```
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene1/差生-中文.png
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene1/中等生-中文.png
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene1/优等生-中文.png

prompts/comic/versions/v2026-04-29-filled-content/prompts/scene2/差生-中文.png
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene2/中等生-中文.png
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene2/优等生-中文.png
```

### 2. 放置图片文件
确认最终图片后，将图片重命名并复制到 PDF 运行目录：

```
static/comic/scene1/差生-中文.png
static/comic/scene1/中等生-中文.png
static/comic/scene1/优等生-中文.png

static/comic/scene2/差生-中文.png
static/comic/scene2/中等生-中文.png
static/comic/scene2/优等生-中文.png
```

### 3. 生成PDF报告
运行PDF生成服务，系统会自动根据学生等级选择对应的漫画图片。

批量渲染样本时，可以直接指定提示词版本下的 PNG 图片。脚本会扫描 `samples/json/` 下所有 `.json` 文件并生成对应 PDF：

```bash
python scripts/render_all_samples.py 2 --comic-version v2026-04-29-filled-content
```

该命令会读取：

```text
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene1/<等级>-中文.png
prompts/comic/versions/v2026-04-29-filled-content/prompts/scene2/<等级>-中文.png
```

不指定 `--comic-version` 时，仍读取默认 PDF 运行目录：

```text
static/comic/scene1/
static/comic/scene2/
```

## 技术实现细节

### 学生等级判断逻辑
```jinja2
{% if acc < 60 %}
  {% set tier = 'need_major' %}
  {% set tier_name = '差生' %}
{% elif acc < 85 %}
  {% set tier = 'room_grow' %}
  {% set tier_name = '中等生' %}
{% else %}
  {% set tier = 'excellent' %}
  {% set tier_name = '优等生' %}
{% endif %}
```

### 动态图片加载

渲染脚本会根据学生等级选择对应图片：

```text
static/comic/scene1/<等级>-中文.png
static/comic/scene2/<等级>-中文.png
```

渲染流程统一读取 `.png` 文件，图片会被转换为 Data URI 后注入模板变量 `comic_scene1_path` 和 `comic_scene2_path`。

## 注意事项

1. **图片分辨率**：建议使用高分辨率图片（长边1500px以上），确保PDF打印质量
2. **图片格式**：统一使用PNG格式，支持透明背景
3. **文件命名**：严格按照 `[等级]-中文.png` 格式命名，区分大小写
4. **画面文案**：图片内直接生成示例文案，不再保留空白区域
5. **主题一致性**：确保漫画图片的色调与Cyan/Purple/Orange主题协调

## 故障排查

### 问题1：图片不显示
**可能原因**：
- 图片文件名不正确
- 图片路径错误
- 图片格式不支持

**解决方法**：
1. 检查文件名是否为 `差生-中文.png` 等
2. 检查图片是否放置在 `static/comic/scene1/` 或 `scene2/` 目录下
3. 检查浏览器控制台是否有加载错误

### 问题2：等级判断不正确
**可能原因**：
- 准确率数据为空或格式错误

**解决方法**：
1. 检查 `summary.current_accuracy` 字段是否存在
2. 确认数据为数字类型

### 问题3：样式显示异常
**可能原因**：
- CSS文件未正确加载

**解决方法**：
1. 确认 `comic_scene1.css` 和 `comic_scene2.css` 存在于 `templates/css/` 目录
2. 检查CSS路径是否正确

## 后续优化建议

1. **图片压缩**：对漫画图片进行适当压缩，减小PDF文件体积
2. **动画效果**：如果需要在线预览，可以考虑添加CSS动画
3. **响应式布局**：优化移动端显示效果
4. **多语言支持**：按同样版本结构规划英文版图片目录，支持国际化
