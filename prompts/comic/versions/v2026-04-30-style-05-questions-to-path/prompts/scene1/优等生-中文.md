# 场景 1：从题目中看见问题（高阶突破版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长陪孩子从高阶题中看见突破问题”，风格为从一堆题到一条路的概念插图。

画面左侧是一组高阶题卡、易失分标记和知识点碎片；画面中间是家长和孩子一起整理这些内容。家长把少数关键高阶问题归类成清晰模块，孩子逐渐看懂自己下一阶段的突破方向。

模块标签可以写成少量清晰文字：

```text
高阶题型
易失分点
优势巩固
突破路径
```

画面要让家长感到：优秀学生的陪伴不是加压，而是精细复盘，让优势更稳、短板更清楚。

可出现的报告式文字：

```text
高阶题复盘
从问题到路径
定位突破点
稳住优势
```

情绪克制、专注、目标清楚。孩子认真但不紧绷，家长陪伴但不施压。

视觉为报告级扁平插画，干净、克制、有信息层次，低饱和配色，留白充足。左侧略复杂，右侧逐渐清晰。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要夸张漫画、二次元、Q 版、竞赛宣传海报、高饱和渐变、成绩焦虑或过度煽情。
