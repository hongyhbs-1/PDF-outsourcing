# 场景 1：从题目中看见问题（基础薄弱版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长陪孩子从一堆基础错题中看见问题”，风格为从一堆题到一条路的概念插图。

画面左侧是一堆看似杂乱但不压迫的题目纸张、错题标记和知识点碎片；画面中间是家长和孩子一起整理这些内容。家长把零散题目归类成几个清晰基础模块，孩子逐渐看懂自己先要处理的关键问题。

模块标签可以写成少量清晰文字：

```text
基础概念
高频错题
易混知识点
第一步
```

画面要让家长感到：陪孩子分析题目、整理错题、归纳短板，不是琐碎劳动，而是在帮孩子建立第一份清晰感。

可出现的报告式文字：

```text
从题目到路径
从问题到方法
优先突破：基础错题
先看清问题
```

情绪温暖、被看见、降低焦虑。孩子从“题目太多”转向“我知道先做哪一步”。

视觉为报告级扁平插画，干净、克制、有信息层次，低饱和配色，留白充足。左侧略复杂，右侧逐渐清晰。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要夸张漫画、二次元、Q 版、营销海报、高饱和渐变、责备场面、过度煽情。
