# 场景 1：从题目中看见问题（稳步提升版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长陪孩子从反复出错的题目中看见核心问题”，风格为从一堆题到一条路的概念插图。

画面左侧是一堆看似杂乱但不压迫的题目纸张、错题标记和知识点碎片；画面中间是家长和孩子一起整理这些内容。家长把零散题目归类成几个清晰模块，孩子逐渐看懂自己的反复卡点。

模块标签可以写成少量清晰文字：

```text
题型归类
错因分析
核心短板
专项训练
```

画面要让家长感到：陪孩子分析题目、整理错题、归纳短板，不是琐碎劳动，而是在把努力变成方向。

可出现的报告式文字：

```text
从题目到路径
从问题到方法
优先突破：高频错题
努力变成方向
```

情绪温暖、清晰、被看见。孩子从困惑转向理解，家长的整理过程成为画面的情绪核心。

视觉为报告级扁平插画，干净、克制、有信息层次，低饱和配色，留白充足。左侧略复杂，右侧逐渐清晰。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要夸张漫画、二次元、Q 版、营销海报、高饱和渐变、过度煽情或大面积文字口号。
