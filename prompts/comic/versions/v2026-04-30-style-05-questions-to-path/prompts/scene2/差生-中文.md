# 场景 2：从问题走向路线（基础薄弱版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“基础问题被整理成孩子能走的成长路线”，风格为从一堆题到一条路的概念插图。

画面左侧的题目纸张和知识点碎片逐渐被整理成右侧一条清晰成长路线。家长和孩子站在路线旁，路线有基础补弱节点、复盘节点和小旗帜。构图表达“家长把复杂问题整理成孩子能看懂的成长路径”。

路线节点可以写成少量清晰文字：

```text
基础回补
高频错题
小步练习
阶段复盘
稳定进步
```

画面情绪要让家长看到自己的陪伴和整理正在变成孩子的第一段行动路线。

可出现的报告式文字：

```text
陪伴看见成长
下一阶段：基础补弱
先走稳第一步
方向更清楚
```

情绪安心、清楚、逐步建立信心。避免制造“落后”的羞耻感。

视觉为报告级扁平插画，低饱和、干净、有信息层次。左侧零散内容向右侧清晰路径自然过渡。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要夸张漫画、二次元、Q 版、高饱和渐变、营销海报、责备场面、过度煽情或压迫感。
