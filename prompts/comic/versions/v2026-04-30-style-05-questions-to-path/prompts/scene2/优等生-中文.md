# 场景 2：从问题走向路线（高阶突破版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“高阶问题被整理成突破路线”，风格为从一堆题到一条路的概念插图。

画面左侧的高阶题卡和易失分标记逐渐被整理成右侧一条清晰突破路线。家长和孩子站在路线旁，路线有高阶专项节点、优势巩固节点和柔和目标旗帜。构图表达“高标准被拆成可执行步骤”。

路线节点可以写成少量清晰文字：

```text
易失分点
高阶专项
优势巩固
稳定拔高
目标清晰
```

画面情绪要让家长看到自己的精细陪伴正在帮助孩子稳住优势、看清突破方向。

可出现的报告式文字：

```text
下一阶段：高阶突破
精细复盘
稳住优势
清晰前进
```

情绪克制、坚定、有方向。孩子专注而不焦虑，家长支持而不压迫。

视觉为报告级扁平插画，低饱和、干净、有信息层次。左侧零散内容向右侧清晰路径自然过渡。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要夸张漫画、二次元、Q 版、高饱和渐变、竞赛宣传海报、成绩焦虑或压迫式冲刺氛围。
