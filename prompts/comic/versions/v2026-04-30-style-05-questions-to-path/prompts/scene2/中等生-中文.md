# 场景 2：从问题走向路线（稳步提升版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“反复出错的问题被整理成稳步提升路线”，风格为从一堆题到一条路的概念插图。

画面左侧的题目纸张和知识点碎片逐渐被整理成右侧一条清晰成长路线。家长和孩子站在路线旁，路线有目标节点、复盘节点和小旗帜。构图表达“家长把复杂问题整理成孩子能看懂的成长路径”。

路线节点可以写成少量清晰文字：

```text
专项训练
错因复盘
重点突破
稳步提升
目标清晰
```

画面情绪要让家长看到自己的陪伴和整理正在变成孩子可执行的行动路线。

可出现的报告式文字：

```text
陪伴看见成长
下一阶段：专项训练
重点突破
稳步提升
```

情绪温暖、清晰、有掌控感。孩子看向路线前方，家长在旁边陪伴推进。

视觉为报告级扁平插画，低饱和、干净、有信息层次。左侧零散内容向右侧清晰路径自然过渡。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要夸张漫画、二次元、Q 版、高饱和渐变、营销海报、过度煽情或大面积文字口号。
