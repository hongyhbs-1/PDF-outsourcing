# 场景 1：夜灯下看清问题（基础薄弱版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长在夜灯下陪孩子把基础问题看清楚”，风格为书桌夜灯复盘。

整洁书桌上有摊开的试卷、错题本、荧光笔、便签纸、知识点卡片和一份简洁学习分析报告。温暖台灯照亮桌面，家长正在圈出基础错因，孩子坐在旁边认真看着标注。孩子可以略显不安，但要被理解和支持。

画面重点表达：家长为孩子分析了很多典型题，默默把复杂问题整理成清晰方向，让孩子知道可以先从基础关键点开始。

可出现的报告式文字：

```text
逐题分析
定位基础短板
先从关键点开始
每一次复盘都有意义
```

情绪温柔、坚定、降低焦虑。不要表现疲惫、责备或深夜压迫感，夜灯应当像陪伴的光，而不是熬夜的压力。

视觉为高级教育类报告插图，半扁平轻写实，低饱和配色，台灯光线温暖但不昏暗。背景干净，使用暖米白、浅青绿、柔和灰蓝和浅沙色。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、夸张漫画、营销海报、焦虑哭泣、训斥场景、高饱和夜景。
