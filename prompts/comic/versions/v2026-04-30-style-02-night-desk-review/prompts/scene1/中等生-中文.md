# 场景 1：夜灯下看清问题（稳步提升版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长在夜灯下陪孩子复盘反复出错的题型”，风格为书桌夜灯复盘。

整洁书桌上有摊开的试卷、错题本、荧光笔、便签纸、知识点卡片和一份简洁学习分析报告。温暖台灯照亮桌面，家长把几类错题归并到不同便签上，孩子在旁边看着自己的学习路线卡片。

画面重点表达：孩子已有基础，但真正的提升来自把零散错题整理成可理解的原因和方向。

可出现的报告式文字：

```text
逐题分析
定位核心短板
阶段复盘
努力变成路线
```

情绪安静、专注、逐渐清晰。家长要体现耐心复盘，孩子从困惑转为理解。

视觉为高级教育类报告插图，半扁平轻写实，低饱和配色，台灯光线温暖但不昏暗。背景干净，使用暖米白、浅青绿、柔和灰蓝和浅沙色。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、夸张漫画、营销海报、焦虑表情、高饱和夜景或大面积文字口号。
