# 场景 2：夜灯下制定计划（稳步提升版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长和孩子在夜灯下把复盘结果整理成可执行计划”，风格为书桌夜灯复盘。

桌面上有学习报告、错题卡、计划清单和温暖台灯。孩子把专项任务卡贴到小型成长板上，家长在旁边温和指向下一阶段。画面要有“从复盘到行动”的清晰转化。

计划节点可以写成少量清晰文字：

```text
专项训练
错因复盘
重点突破
稳步提升
```

画面表达：家长的分析不是停留在题目上，而是变成孩子能执行的成长计划。

可出现的报告式文字：

```text
下一阶段：专项训练
重点突破
目标逐步清晰
陪伴成长
```

情绪温暖、清晰、稳步推进。孩子要显得更有掌控感，家长要像稳定的陪伴者。

视觉为高级教育类报告插图，半扁平轻写实，低饱和配色，温暖但克制。台灯形成柔和视觉中心，页面适合 PDF 报告。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、夸张漫画、营销海报、高饱和渐变、戏剧化情绪或大面积文字口号。
