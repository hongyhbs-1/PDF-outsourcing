# 场景 2：夜灯下制定计划（高阶突破版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长和孩子在夜灯下把高阶复盘整理成突破计划”，风格为书桌夜灯复盘。

桌面上有学习报告、高阶题卡、易失分点便签、计划清单和温暖台灯。孩子把高阶专项任务卡贴到小型成长板上，家长在旁边温和指向下一步。画面要表达克制的目标感。

计划节点可以写成少量清晰文字：

```text
易失分点
高阶专项
优势巩固
稳定拔高
```

画面表达：高标准不是单纯加压，而是和孩子一起把优势做稳，把关键短板补上。

可出现的报告式文字：

```text
下一阶段：高阶突破
稳住优势
精细复盘
清晰前进
```

情绪克制、坚定、有方向。孩子专注而不紧绷，家长支持而不压迫。

视觉为高级教育类报告插图，半扁平轻写实，低饱和配色，温暖但克制。台灯形成柔和视觉中心，页面适合 PDF 报告。
