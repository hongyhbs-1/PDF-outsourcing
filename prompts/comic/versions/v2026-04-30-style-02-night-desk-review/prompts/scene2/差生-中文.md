# 场景 2：夜灯下制定计划（基础薄弱版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长和孩子在夜灯下把基础问题整理成下一阶段计划”，风格为书桌夜灯复盘。

桌面上有学习报告、错题卡、计划清单和温暖台灯。孩子把任务卡贴到小型成长板上，家长在旁边温和指向第一步。成长板上的节点清晰简单，强调从基础关键点开始。

计划节点可以写成少量清晰文字：

```text
基础回补
高频错题
小步练习
阶段复盘
```

画面表达：家长的分析不是制造压力，而是把混乱问题变成孩子能执行的小步骤。

可出现的报告式文字：

```text
下一阶段：基础补弱
先完成第一步
方向已经清楚
陪伴成长
```

情绪安心、温暖、有方向。夜晚氛围要克制，不能像熬夜赶作业或家长施压。

视觉为高级教育类报告插图，半扁平轻写实，低饱和配色，温暖但克制。台灯形成柔和视觉中心，页面适合 PDF 报告。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、夸张漫画、营销海报、高饱和渐变、戏剧化情绪、责备或压迫感。
