# 场景 1：翻开成长档案（稳步提升版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长和孩子翻开稳步提升的成长档案”，风格为成长档案册。

画面中有一本打开的成长档案册，里面整齐排列学习记录卡、错题分析卡、阶段目标卡和家长陪伴记录卡。家长和孩子一起翻看档案册，家长指向一页错因归类，孩子露出理解和安心的表情。

档案卡片可以写成少量清晰文字：

```text
错题复盘
核心短板
阶段目标
陪伴轨迹
```

画面表达：家长不是简单看分数，而是长期记录、分析、复盘，陪孩子看见自己的变化。

可出现的报告式文字：

```text
整理多份练习与试卷
成长记录
持续复盘
努力被整理成方向
```

情绪温暖、安静、逐渐清晰。孩子看到自己努力的轨迹，家长看到陪伴被记录下来。

视觉为轻纸感拼贴与温暖手绘结合，浅米色纸张、青绿色标签、暖黄色重点标记、蓝灰文字线。整体干净、有报告感，不像儿童绘本。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、商业宣传海报、高饱和配色、空白卡片或夸张庆祝。
