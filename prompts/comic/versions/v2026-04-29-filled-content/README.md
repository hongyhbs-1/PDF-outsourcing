# v2026-04-29-filled-content

## 目标

本版本将旧提示词中的“预留留白后续填充”改为“图片内直接生成合适内容”。提示词不覆盖旧版本，生成图也按版本单独保存。

## 机构占位名

当前使用：`星航优学中心`

正式机构名称确定后，对本版本提示词中的 `星航优学中心` 做全文替换即可。替换后如需保留历史，请新建下一个版本目录，不要覆盖本版本。

## 画面策略

- 不保留空白标签、空白横幅、空白海报、空白成绩单。
- 所有原本留白的位置都直接生成可读文案。
- 文案要短、字号大、横向正放，避免密集小字。
- 画面中的机构名称使用 `星航优学中心`，后续替换。
- 继续保持两页漫画的视觉主题：场景1从冷色过渡到暖色，场景2从琥珀色过渡到金橙色。

## 输出图片命名

同一提示词生成的最终候选图放在对应提示词同目录，统一使用 PNG：

```text
prompts/scene1/差生-中文.png
prompts/scene1/中等生-中文.png
prompts/scene1/优等生-中文.png
prompts/scene2/差生-中文.png
prompts/scene2/中等生-中文.png
prompts/scene2/优等生-中文.png
```

选定上线图片后，再复制到 `static/comic/scene1/` 和 `static/comic/scene2/`。
