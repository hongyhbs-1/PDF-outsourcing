# 场景 2：痕迹连成成长路（基础薄弱版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“基础补弱的陪伴痕迹连成成长路”，风格为家长视角纪念页。

成长墙上的题目卡、基础错因便签和阶段小结逐渐连成一条温暖成长路线。家长和孩子站在路线前方，看到下一阶段目标。路线不夸张，像报告里自然延展出的学习路径。

路线节点可以写成少量清晰文字：

```text
看见问题
基础补弱
小步练习
阶段复盘
稳定进步
```

画面表达：家长过去每一次陪伴，都在帮助孩子从混乱走向清晰第一步。

可出现的报告式文字：

```text
一起走过的学习路
下一阶段：基础补弱
目标逐步清晰
陪伴看见成长
```

情绪温柔、克制、有希望感。不要催泪或戏剧化，要像正式报告中一页温暖的情绪插图。

视觉为高级纸感拼贴与手绘插画结合，低饱和、留白充足、报告内页质感。路线由墙面卡片自然连接而成。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、奇幻路线、营销海报、高饱和渐变、责备或压迫感。
