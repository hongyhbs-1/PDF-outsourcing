# 场景 2：痕迹连成成长路（高阶突破版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“高阶突破的陪伴痕迹连成成长路”，风格为家长视角纪念页。

成长墙上的高阶题卡、易失分点便签和优势巩固记录逐渐连成一条温暖成长路线。家长和孩子站在路线前方，看到下一阶段高阶目标。路线不夸张，像报告里自然延展出的学习路径。

路线节点可以写成少量清晰文字：

```text
高阶复盘
易失分点
专项突破
优势巩固
稳定拔高
```

画面表达：家长过去每一次精细陪伴，都在帮助孩子稳住优势、看清更高目标下的下一步。

可出现的报告式文字：

```text
一起走过的学习路
下一阶段：高阶突破
稳住优势
清晰前进
```

情绪克制、坚定、有高级感。不要催泪或戏剧化，要像正式报告中一页温暖的情绪插图。

视觉为高级纸感拼贴与手绘插画结合，低饱和、留白充足、报告内页质感。路线由墙面卡片自然连接而成。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、奇幻路线、竞赛宣传海报、高饱和渐变、成绩焦虑。
