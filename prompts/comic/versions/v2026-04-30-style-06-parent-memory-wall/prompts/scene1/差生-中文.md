# 场景 1：看见陪伴的痕迹（基础薄弱版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长看见基础补弱过程中留下的陪伴痕迹”，风格为家长视角纪念页。

画面中是一面温暖成长墙，上面贴着整理过的题目卡、基础错因便签、学习路线和阶段小结。家长和孩子站在成长墙前回望过去的努力。孩子可以显得曾经不安，但现在更安心，因为问题已经被整理出来。

成长墙内容可以写成少量清晰文字：

```text
基础错题
错因复盘
第一步计划
陪伴记录
```

画面强调家长投入的价值：分析典型题、整理练习、复盘错因、规划下一阶段。

可出现的报告式文字：

```text
每一次分析都算数
每一段陪伴都有痕迹
整理多份练习与试卷
从基础开始
```

情绪温暖、克制、被看见。不要催泪，不要夸张拥抱；重点是家长觉得自己的陪伴终于被报告记录下来。

视觉为高级纸感拼贴与手绘插画结合，暖米白、浅青绿、柔和灰蓝、浅沙色，少量暖金色点缀。报告内页质感，留白充足。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、营销海报、高饱和渐变、戏剧化煽情、责备或压迫感。
