# 场景 1：看见陪伴的痕迹（高阶突破版）

适合放入学生学情诊断报告的 A4 竖版教育插图。主题是“家长看见高阶突破过程中留下的陪伴痕迹”，风格为家长视角纪念页。

画面中是一面温暖成长墙，上面贴着高阶题卡、易失分点便签、优势巩固记录和阶段小结。家长和孩子站在成长墙前回望过去的努力，孩子看到自己从稳定优秀走向更精细突破的路线。

成长墙内容可以写成少量清晰文字：

```text
高阶复盘
易失分点
优势巩固
突破路径
```

画面强调家长投入的价值：不只是督促成绩，而是陪孩子做精细复盘、稳住优势、看清突破点。

可出现的报告式文字：

```text
每一次分析都算数
每一段陪伴都有痕迹
精细复盘
优势要稳住
```

情绪克制、坚定、有高级感。不要催泪，不要夸张拥抱；重点是家长觉得自己的精细陪伴被记录下来。

视觉为高级纸感拼贴与手绘插画结合，暖米白、浅青绿、柔和灰蓝、浅沙色，少量暖金色点缀。报告内页质感，留白充足。

不要出现真实姓名、学校、具体题目数量、具体分数或真实输入内容。不要二次元、日漫、网漫、Q 版、竞赛宣传海报、高饱和渐变、成绩焦虑或戏剧化煽情。
