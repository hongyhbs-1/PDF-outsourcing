# v2026-04-30-style-01-growth-route-map

风格：温暖陪伴路线图。

用途：作为可通过 `--comic-version v2026-04-30-style-01-growth-route-map` 切换的漫画图片版本目录。

提示词与图片放置规则：

```text
prompts/scene1/差生-中文.md
prompts/scene1/中等生-中文.md
prompts/scene1/优等生-中文.md
prompts/scene2/差生-中文.md
prompts/scene2/中等生-中文.md
prompts/scene2/优等生-中文.md
```

生成后的图片保存为同目录同名 `.png` 文件，例如 `prompts/scene1/差生-中文.png`。

场景说明：

- `scene1`：家长陪孩子看清问题与短板。
- `scene2`：家长陪孩子走向清晰成长路线。
