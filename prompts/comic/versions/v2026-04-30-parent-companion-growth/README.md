# v2026-04-30-parent-companion-growth

## 目标

本版本将原来的 Q 版漫画路线调整为“家庭陪伴成长”报告插图路线。目标是让漫画页与正式学情诊断报告的色彩、形式、情绪保持统一。

本版本优先用于美工出初稿，不建议直接用 Gemini 或 GPT-2 产出定稿图。美工初稿通过后，再基于确认后的画风继续生成或绘制正式图片。

## 核心方向

- 不再做夸张漫画剧情。
- 不再突出机构宣传、入学、庆祝等外部情节。
- 改为家长陪孩子分析题目、整理错题、看清短板、制定成长路线的温暖叙事。
- 情绪目标是“用户自我感动型”：让家长看到自己的陪伴、付出和分析过程被报告记录下来。
- 图片要像正式教育报告中的情绪插图，不像独立漫画海报。

## 场景

```text
prompts/
  scene1/
    差生-中文.md
    中等生-中文.md
    优等生-中文.md
  scene2/
    差生-中文.md
    中等生-中文.md
    优等生-中文.md
```

场景说明：

- 场景 1：家长陪孩子一起看清问题。
- 场景 2：家长和孩子一起走出成长路线。

三档学生版本只调整情绪和学习状态，不改变整体画风。

## 图片保存

美工初稿或生成候选图保存到：

```text
images/scene1/
images/scene2/
```

最终确认后，再复制到：

```text
static/comic/scene1/
static/comic/scene2/
```
