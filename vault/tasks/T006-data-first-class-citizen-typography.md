# T006: 数据为第一公民 — 层级排版统一深度重设计

## 背景

T005 完成了架构重设计（合约层 + 适配器层 + 引擎拆分），解决了代码结构问题。
但核心命题尚未完成：**如果 JSON 数据包是第一公民，层级排版应该怎么做？**

当前痛点：
1. CSS 仍是最高公民 — 25 个 CSS 文件 492KB，硬编码排版参数
2. 模板包含业务判断逻辑（`{% if items|length > 6 %}`）
3. 数据特征（领域数、题量、密度）无法影响排版决策
4. 排版参数分散在 CSS/模板/渲染脚本三处
5. 不同模块的视觉层级不统一（M1 和 M4 的卡片样式不一致）

## 第一性原理调研（进行中）

从数据出发，重新审视层级排版系统。
